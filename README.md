# Vitalsly — Premium Fitness & Workout Tracker

A small static site (vanilla HTML/CSS/JS, no frameworks, no CDN, no build step) that logs
workouts, tracks streaks and visualizes the last 7 days of training.

## Features
- Glassmorphism dark UI with gradient headline and glow accents
- Animated daily-goal progress ring
- Quick-log form with automatic calorie estimate
- Last-7-days bar chart, weekly goals meters and streak counter
- Sessions persisted in `localStorage`
- Fully responsive from 360px, semantic HTML with ARIA labels

## Files
- `index.html`
- `css/styles.css`
- `js/main.js`

## Run
Open `index.html` in any modern browser, or serve the folder with any static server.
